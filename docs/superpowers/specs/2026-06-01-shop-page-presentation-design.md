# Shop Page Presentation Design

## Goal

調整購買階段商店的資訊呈現，讓玩家能在表單本文集中看到點數與目前裝備選擇，並簡化商品按鈕文字。

## Requirements

-   表單 BODY 顯示目前已使用點數、點數上限、剩餘點數、主武器、副武器、護甲與投擲物。
-   武器與護甲按鈕只顯示商品名稱與所需點數。
-   投擲物按鈕顯示商品名稱、目前持有數量、單項上限與所需點數。
-   主武器分頁固定顯示「移除主武器」按鈕，按下後清空主武器；沒有主武器時也不報錯。
-   投擲物分頁固定顯示「全部清空」按鈕，按下後清除所有投擲物；沒有投擲物時也不報錯。
-   不再顯示單一投擲物移除按鈕。

## Implementation Notes

-   `Shop.ts` 負責建構 BODY、商品按鈕與分頁控制按鈕。
-   `LoadoutManager` 新增清除主武器的方法，並沿用既有 `clearThrowables`。
-   語系字串維持集中於 `zh_TW.ts`。
